# ريل Custom Smart TV: كود الموشن

ريل عمودي 1080×1920، 30fps، بصوت محمد الحقيقي، بأسلوب Kinetic Typography عربي. النسخة المعتمدة v06، ومدتها 62.5 ثانية.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | الموشن كله: كل إطار ينرسم من الوقت `t` فقط (`renderAt(t)`) |
| `render.mjs` | يفتح الصفحة في Chromium ويصوّر الإطارات |
| `transcribe.py` | تفريغ الصوت بـ faster-whisper (large-v3-turbo) مع توقيت كل كلمة |
| `prep.py` | يصحح أخطاء التفريغ، ويقصّر السكتات الأطول من 0.45 ث، ويكتب `timeline.json` و`edit.json` |
| `mix.py` | يقص السكتات من الصوت ويضيف المؤثرات الصوتية |
| `build.sh` | يبني الفيديو كامل |
| `timeline.json` | نص الكلام المعتمد مع التوقيتات بعد تقصير السكتات |

## إعادة البناء

1. حط التسجيل الأصلي في `input/voice.m4a`. **لا ترفعه للمستودع**، لأن المستودع عام و`.gitignore` يستثنيه.
2. شغّل `./build.sh`. الناتج يطلع في `out/TVReel.mp4`.

## قواعد المحتوى

- ما فيه شعارات ولا لقطات شاشة لتطبيقات أو شركات حقيقية. اسم Claude Code مكتوب كنص فقط.
- كل واجهة توضيحية عليها وسم «تصوّر توضيحي · حسب دعم الجهاز».
- الكلام ما يتلمس: لا تسريع ولا قص كلمات. اللي يتقصّر بس السكتات الطويلة.
- المؤثرات الصوتية مولّدة من الصفر، وما فيه موسيقى.
